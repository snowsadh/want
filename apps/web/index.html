Install WANT!

  1. 1

    Download the installer

    No backend setup or API keys required.

    ↓ Download for macOS

    Other system: macOS · Windows

  2. 2

    Run it

    Open the ZIP, then open install-want.command. It downloads WANT!, copies its folder path, and opens Chrome Extensions.

  3. 3

    Approve it in Chrome

    Turn on Developer mode, choose Load unpacked, press Command + Shift + G, paste the copied path, and select the folder.

  4. 4

    Open WANT!

    Add your full-body photo once. Then use the extension anywhere on the web.

    Alt+Wopens and closes WANT!
